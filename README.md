# zaizai

我在这里，也在你身边。

面向 Windows 和 macOS 的本地桌面应用，提供一次性任务、日/周/月周期计划、任务优先级、定时提醒、互动宠物和固定下班倒计时。

已在 M1 正式数据基础上接入 M2 任务界面：一次性任务编辑、日/周/月多时间计划管理、日期历史、未来预览与移到今天。全部操作复用主进程任务服务和六张核心表。macOS Apple Silicon 已执行本机验证，尚未完成双平台验收。

## 运行应用

需要 Node.js 22.12 或更新版本。首次安装会下载 Electron 运行时并构建 SQLite 原生模块。

```sh
npm install
npm run dev
```

底部输入内容后回车或点 `＋`，快捷新增当前查看日期的无时间待办，默认是今天；点击“周期”设置日期、时间或日/周/月计划。快捷栏的“紧急”和任务行的星标可切换优先级，紧急事项优先，同一优先级内按时间排序。任务行 `✎` 打开编辑，`×` 删除本次；重复实例的编辑入口打开所属计划。

顶栏日历图标用于查看历史待办和未来安排，悬停可见用途提示。点击后打开覆盖式月历，说明用途，并标点提示有历史记录的日期；选择某天自动关闭，清单与输入栏保持原位置。非今日日期和「回今天」合并在进度行。未来视图新增到那一天，历史页提供「移到今天」操作和提示。

双击宠物切换完整清单与仅桌宠模式，胶囊和菜单栏始终统计今天。关闭按钮提供隐藏、退出、取消三个选项，隐藏后仍调度提醒。编辑器保存失败保留草稿；版本冲突时可以主动重新载入最新记录。

完成待办后会弹性打勾、迸出星星与爱心、划过删除线并盖上猫爪章，星光飞向宠物后任务行平滑收起。前 620 毫秒可再次勾选撤销；任务先保存，动画不会延迟落库。收起清单时卡片向上折叠、淡出，再缩小原生窗口，展开时反向播放；系统开启“减少动态效果”时使用直接反馈。

内置桌宠包含「草莓兔女孩 V3」、「胡娴雅 · 室内设计师」、「滕环 · 前端工程师」和「滕俊龙 · 路桥工程师」。顶栏 `🐾` 面板中的「桌宠角色」可切换角色，选择保存到本地，重启后恢复；已有选择继续保留。点击角色会挥手，完成任务会鼓掌，完成今天的全部任务会跳跃欢呼；回应与完成台词使用所选角色的配置。到点提醒按任务明确选择的“提醒动作”播放摇铃、喝水或拉伸。面板可连续预览七组动作，返回清单后恢复正常互动。隐藏、锁屏或休眠时暂停动画，未处理的提醒始终优先。

四套内置包共二十八张精灵图参与构建，V1/V2、预览页、APNG 和生成记录不进入应用包；图片由应用自身协议加载，不依赖预览服务器。旧的内置占位角色 ID 继续对应到 V3，已有任务与偏好保留；角色选择保存失败时维持当前角色并提示重试。用户素材导入仍属于后续扩展。

```sh
npm run test       # 使用 Electron Node ABI 验证迁移、任务与提醒规则
npm run build      # 类型检查与构建
npm run smoke      # 隔离数据目录的真实 Electron 回归
node scripts/pet-smoke.mjs # 隔离数据目录的四角色、持久化切换与事件播放检查
node scripts/animation-smoke.mjs # 完成/撤销、保存失败、菜单过渡与减少动态效果
node scripts/calendar-smoke.mjs # 日期浮层、布局、未来新增与历史迁移
node scripts/scheduling-smoke.mjs # 优先级、周/月计划、缩放、层级、声音与自启失败恢复
npm run pack:mac   # 本机测试包，使用 ad-hoc 本地签名
npm run pack:win   # Windows x64 NSIS 安装包
```

macOS 本机应用包位于 `release/mac-arm64/zaizai.app`，压缩包为 `release/zaizai-0.1.0-mac-arm64.zip`。Windows x64 安装包为 `release/zaizai Setup 0.1.0.exe`，支持选择安装目录并创建桌面与开始菜单快捷方式。本轮两端测试包已更新，包含四角色、v0.3 周/月计划、优先级、声音和桌面偏好；新增扩展和 macOS 打包版验证见 [v0.3 记录](docs/v0.3-verification.md)。此前角色专项验收见 [角色接入记录](docs/m2-verification.md#2026-11-03-胡娴雅接入与角色切换)。应用显示名和图标使用用户确认的 zaizai 品牌，原应用标识与数据目录继续保留，承接已有任务与通知身份。图标源文件、各平台格式与提示词见 [图标资源](resources/branding/README.md)。Windows 包由 macOS 交叉构建，未签名；安装器、内嵌应用归档完整性及包内资源检查通过，尚无 Windows 真机结果，详见 [Windows 打包记录](docs/m2-verification.md#windows-x64-安装包2026-11-03)。系统通知优先使用独立应用包验证，开发运行时可能受 Electron 自身应用身份与系统授权影响。

「滕环 · 前端工程师」v1.0.2 与「滕俊龙 · 路桥工程师」v1.0.1 已进入当前源码和生产构建；滕俊龙包含修订后的待机眨眼及其余六组动作。`release/` 中的两端测试包已包含全部四角色和本轮六项功能。

当前锁定的 `better-sqlite3@13.0.3` 自带 Node-API 10 各平台二进制，运行时按平台和架构加载。`pack:win` 关闭额外的原生模块重建，直接包含依赖自带的 Windows x64 模块，以支持 macOS 交叉打包；后续更换原生依赖时需重新核对。

首次打开旧库会先生成同目录 `*.pre-v3-*.bak`，再执行事务迁移。失败时保留旧库、显示错误与数据目录入口，不会创建空库替代。数据位置与手动恢复方式见 [M1 验证记录](docs/m1-verification.md)。

周计划可多选星期；月计划可多选 1～31 号，也可选“每月最后一天”。小月没有的日期跳过，月末选项与具体日期重合时只生成一次。修改、暂停和结束计划保留已到点、已完成与手动迁移的记录；任务行切换紧急只影响本次安排。

顶栏 `📌 置顶 / 🖥 桌面`、宠物右键和系统菜单可切换层级。拖拽右下角 `↘` 自由缩放，双击切换标准 `356×480` 与大号 `440×610`；设置中的预设提供同样操作。展开尺寸保存在 SQLite，收起及重启后恢复，并限制在可用显示器范围内。

`⚙` 中可设置开机自启、提醒声音与固定下班时间。自启默认关闭，仅安装版写入系统登录项，并校验系统返回状态；系统拒绝时显示错误并回滚，开发运行不会注册 Electron 自启。每批到点任务只播放一次与原型一致的合成摇铃，窗口隐藏也可播放；关闭声音后系统通知同样静音。`试听` 是主动预览，可在静音时播放。

## 体验交互原型

克隆仓库后，用浏览器打开 [双平台交互原型](docs/dual-platform-prototype.html)，或在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000/docs/dual-platform-prototype.html>。体验任务新增与完成、日期切换、重复计划、仅桌宠模式、宠物资源库，以及 Windows/macOS 两种桌面布局。

原型通过 CDN 加载 Tailwind CSS，需要联网。示例日期固定为 2026-11-02，数据仅保存在页面内存中，刷新后重置；系统通知、托盘、窗口隐藏与 SQLite 存储均为界面模拟。
