# ZaiZai

面向 Windows 和 macOS 的本地桌面应用，提供一次性任务、每日重复任务、定时提醒、互动宠物和固定下班倒计时。

已在 Electron M0 上接入 M1 正式数据基础：六张核心表、迁移前备份、类型化设置、任务与每日计划服务，以及有限 IPC。界面现可保存带日期、可选时间的一次性任务；计划管理与日期历史界面在 M2 接入。macOS Apple Silicon 已执行本机验证，尚未完成双平台验收。

## 运行应用

需要 Node.js 22.12 或更新版本。首次安装会下载 Electron 运行时并构建 SQLite 原生模块。

```sh
npm install
npm run dev
```

应用中可添加一次性任务，时间留空即为无时间待办；指定时间后可点击“添加并隐藏”验证后台调度。双击宠物切换完整清单与仅桌宠模式。关闭按钮提供隐藏、退出、取消三个选项。

```sh
npm run test       # 使用 Electron Node ABI 验证迁移、任务与提醒规则
npm run build      # 类型检查与构建
npm run smoke      # 隔离数据目录的真实 Electron 回归
npm run pack:mac   # 本机测试包，使用 ad-hoc 本地签名
```

macOS 本机应用包位于 `release/mac-arm64/Desktop Buddy M0.app`。为承接 M0 数据与通知身份，本轮保留原应用标识、数据目录和包名；包内容已使用正式模型。Windows 使用 `npm run pack:win`，应在 Windows 构建和验收，当前尚无真机结果。系统通知优先使用独立应用包验证，开发运行时可能受 Electron 自身应用身份与系统授权影响。

首次打开旧库会先生成同目录 `*.pre-v2-*.bak`，再执行事务迁移。失败时保留旧库、显示错误与数据目录入口，不会创建空库替代。数据位置与手动恢复方式见 [M1 验证记录](docs/m1-verification.md)。

## 体验交互原型

克隆仓库后，用浏览器打开 [双平台交互原型](docs/dual-platform-prototype.html)，或在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000/docs/dual-platform-prototype.html>。体验任务新增与完成、日期切换、重复计划、仅桌宠模式、宠物资源库，以及 Windows/macOS 两种桌面布局。

原型通过 CDN 加载 Tailwind CSS，需要联网。示例日期固定为 2026-11-02，数据仅保存在页面内存中，刷新后重置；系统通知、托盘、窗口隐藏与 SQLite 存储均为界面模拟。
