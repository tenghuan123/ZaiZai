# v0.3 六项扩展验证

日期：2026-11-03（Asia/Shanghai）。环境：macOS Apple Silicon，Electron 45.2.1、Chromium 156、Electron Node 24.22.1。界面以当前 `dual-platform-prototype.html` 为基线；以下区分正式实现、自动化检查和原生平台验收。

## 已接入的行为

| 范围 | 正式行为 |
| --- | --- |
| 优先级 | 快捷栏与编辑器选择普通/紧急，任务行星标即时切换；紧急优先，同优先级按时间及标题排列，无时间任务靠后。重复实例的行内切换只影响本次，不改整条计划或提醒安排版本 |
| 周期计划 | 日/周/月统一编辑器，多选星期或月份日期，独立时间槽、起止日期、暂停/恢复/结束和未来预览。具体日期遇小月时跳过，额外支持每月最后一天；重合只生成一份 |
| 自由缩放 | 右下角拖拽，双击切换标准 356×480 与大号 440×610，设置和系统菜单提供同样预设。展开尺寸保存在 SQLite，收起/展开及重启恢复；约束为 356×480 至 520×780，适配显示器可用区域 |
| 桌面层级 | 顶栏、设置、宠物原生右键与托盘/菜单栏切换置顶/仅桌面。后者调用真实 `setAlwaysOnTop(false)` 和 `setSkipTaskbar(true)`，由其他应用正常遮挡 |
| 摇铃音效 | 使用原型的 Web Audio 双泛音音色，一批到点任务只发一个声音信号，窗口隐藏也可播放；系统通知静音以避免双响。设置可静音，主动试听可在静音时播放，角色摇铃预览遵循声音开关 |
| 开机自启 | 默认关闭，安装版写入系统登录项并核对实际状态；开发运行不注册 Electron。系统拒绝、版本冲突或窗口副作用失败时不保存虚假成功，必要时恢复原生状态 |

任务标题与元信息分行，周期计划采用名称/状态和标签/操作两行布局；设置使用分组覆盖式对话框。长编辑器可滚动，失败保留草稿或设置入口。下班时间在编辑时保留输入焦点，关闭设置前保存草稿，失败时保留输入供重试。已完成页保留撤销入口，键盘焦点可见。历史实例对应的旧计划规则已变化时显示通用周期标签，避免把新周期当作历史事实。

## 数据升级与错误处理

SQLite 升级到 `user_version=3`，继续使用六张核心表。v2 计划补为每日/普通，旧实例、完成状态、来源身份、取消墓碑、提醒处理记录、角色和既有偏好保留。迁移前生成包含 WAL 已提交内容的 `*.pre-v3-*.bak`；结构、设置和版本在一个事务中升级，失败回滚，不创建空库替代。

优先级只影响清单顺序，不递增 `schedule_version` 或重新领取旧提醒。计划变更继续保留已到点、已完成及手动迁移的记录；未来预览与当天生成共用同一个周期匹配入口。设置的系统副作用由主进程统一执行，窗口缩放失败恢复已保存尺寸并可通过 IPC 返回错误。

## 本地测试包

- macOS arm64 应用：`release/mac-arm64/zaizai.app`。
- macOS arm64 压缩包：`release/zaizai-0.1.0-mac-arm64.zip`。
- Windows x64 NSIS：`release/zaizai Setup 0.1.0.exe`。

macOS 使用 ad-hoc 本地签名并通过签名验证，未公证；Windows 包未签名，由 macOS 交叉构建。Windows 真机安装、自启动、通知与多屏/真实休眠仍未验收。开发运行的系统通知因权限返回 `UNErrorDomain 1`；提醒记录与应用内处理保持可用，声音信号不依赖系统通知成功。正式分发与跨平台原生验收不因这些本地检查自动完成。

系统 API 依据：[Electron 登录项](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows)、[透明窗口限制](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles#transparent-window)。
