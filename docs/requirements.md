# 桌面任务助手与互动宠物需求文档

版本：0.3。基线日期：2026-11-03。补充优化原型进入架构阶段的对接规则，并纳入用户试用反馈的 6 项新增需求（开机自启动、仅显示在桌面/层级切换、框框自由拉大、紧急/日常优先级排序、周计划与月计划、提醒摇铃声音）。

目标是让用户通过一个常驻桌面的小组件，安排日常生活与临时事项，在指定时间收到提醒，并通过宠物互动获得反馈。围绕任务、提醒、宠物和本地桌面体验形成完整闭环。

依据为用户提供的参考截图、试用反馈截图，以及对话中对任务类型、周期规则、优先级、窗口尺寸、桌面层级、提醒铃声、宠物互动、关闭行为和存储范围的确认。截图上方的关注、分享、头像和图片页码属于发布平台，不计入应用范围。

## 1 范围与决策状态

### 1.1 用户明确确认

| 项目 | 决定 |
| --- | --- |
| 目标平台 | Windows、macOS 桌面应用 |
| 任务类型 | 支持长期重复任务（每天 / 每周 / 每月），以及今天等指定日期的一次性任务 |
| 任务优先级 | 支持区分**紧急任务**与**普通日常任务**，待办列表中紧急任务自动排到最前面 |
| 日常场景 | 吃药提醒、起身运动、准备早饭午饭晚饭、周报月结等，由用户自行设置内容与时间 |
| 提醒声音 | 到点提醒摇铃时支持播放清脆铃声音效，可在设置中开关与试听 |
| 宠物 | 可以互动，使用精灵图动画；素材可自行制作或寻找现成资源 |
| 窗口尺寸 | 支持自由拖拽边缘拉大窗口宽高（限制最小宽高防变形），自动记忆上次尺寸，解决计划多时看不清的问题 |
| 桌面层级 | 顶栏与快捷菜单直接提供「置顶显示 / 仅留在桌面」一键切换；仅留在桌面模式下打开其他软件时可自然遮挡桌宠 |
| 开机自启动 | 支持开启或关闭随系统开机自动启动 |
| 关闭行为 | 点击关闭按钮后，让用户选择隐藏或退出 |
| 数据 | 仅保存在本机，不做跨设备同步 |
| 下班时间 | 固定时间，可在设置中修改 |
| 打卡 | 首版不做；如以后增加，仅表示进入应用开启新一天 |

### 1.2 上一轮方案中已接受的首版默认规则

- 重复任务支持按周期（每天、每周指定星期、每月指定日期）重复，同一执行日支持多个执行时间；每一次执行独立完成。
- 今日清单合并当天的重复任务（含当天命中的日计划、周计划、月计划）与一次性任务，支持待办、已完成切换及今日进度。
- 待办列表按优先级与时间双重排序：紧急任务优先置顶，同优先级内有时间任务按时间升序，无时间任务置于其后。
- 任务可以完成、撤销完成、切换紧急状态；重复计划可以暂停、恢复和结束，历史完成记录保留。
- 前一天未完成的任务保留在历史中，可以手动移到今天，不自动清空或自动完成。
- 窗口隐藏后保持运行与提醒；退出应用后停止提醒。
- 休眠期间错过的提醒在恢复后汇总，不逐条连续补弹。
- 宠物首版接入内置素材，提供待机、点击反馈、完成庆祝和到点摇铃/场景提醒动作（配合可选提醒铃声）。
- 宠物与清单共同组成一个小组件，拖动时一起移动；展开态支持拖拽边缘自由调整窗口大小并记忆尺寸。

## 2 任务概念

“长期任务”表示周期重复计划（日计划、周计划、月计划），不表示一条一直不能结束的任务。

| 概念 | 含义 | 示例 |
| --- | --- | --- |
| 一次性任务 | 在指定日期执行一次，时间可选，可标为紧急或普通 | 今天整理文件（🔥 紧急） |
| 重复计划 | 定义按每天、每周几或每月几号在哪些时间执行什么事项 | 每天 10:00、15:00 起身运动；每周五 16:00 周报汇总；每月 15 日还信用卡 |
| 任务优先级 | 区分 `urgent`（紧急）与 `normal`（普通日常），决定待办排序与视觉权重 | 🔥 紧急任务自动排在普通任务之前 |
| 任务实例 | 某一天某一次实际需要完成的事项 | 今天 10:00 起身运动 |
| 完成记录 | 某个实例的完成状态及完成时间 | 今天 10:08 完成上午运动 |

完成一个实例，只影响该次执行。编辑重复计划，不改写既有完成记录。今日进度按当天命中的实例统计：同一计划当天执行两次，计为两项任务。

## 4 任务业务规则

### 4.1 创建、周期规则与优先级排序

- 快捷新增创建当前查看日期的一次性任务，默认查看今天；快捷新增栏内提供 **「🔥 紧急」** 一键开关，可在回车提交前直接标记为紧急任务。未来视图的输入提示明确对应所选日期。历史视图不提供快捷新增，以查看和「移到今天」为主。
- 任务名称去除首尾空白后不能为空。长度限制为 60 字符，并支持在拉宽后的窗口中展示更多文本。
- **周期重复规则（日计划 / 周计划 / 月计划）**：
  - **每天（`daily`）**：在起止日期范围内的每个自然日生成设定时间槽的实例；
  - **每周（`weekly`）**：用户可勾选周一至周日中的一个或多个星期（`1~7`），仅在匹配的星期生成实例；
  - **每月（`monthly`）**：用户可选择每月 `1~31` 号中的一个或多个日期（或勾选“每月最后一天”），仅在匹配的月份日期生成实例。小月缺少所选日期时跳过；具体日期与“最后一天”重合时只生成一次。
- 重复计划至少有一个时间，同一计划内不允许重复的时间；开始日期不得晚于结束日期。
- **待办优先级与时间排序规则**：
  - 第一优先级：**紧急任务（`priority = 'urgent'`）排在普通日常任务（`priority = 'normal'`）之前**；
  - 第二优先级：同一优先级内，有具体时间的任务按时间升序排列在前，无时间的任务排列在后；
  - 待办行内支持一键点击切换「紧急 / 普通」状态，切换后列表立即按新优先级重排。
- 已完成列表按完成时间倒序。
- 未到时间的当天任务也出现在今日清单中，可以提前完成；已完成任务到点不再提醒。

### 4.2 完成与统计

- 完成与撤销操作立即更新列表和进度，保存成功后才向用户确认成功；写入失败时保留可重试入口。
- 进度为“当天已完成实例数 / 当天有效实例总数”，百分比四舍五入为整数。
- 提醒、关闭气泡和关闭系统通知都不代表任务完成。
- 新增、删除、移入或移出当天任务后重新计算进度，不能将进度当成只增不减的数值。
- “全部完成”庆祝只在用户完成任务使非空清单从未全部完成变为全部完成时触发；空列表和启动恢复不触发。

### 4.3 编辑与结束重复计划

- 首版在计划管理中编辑重复规则，影响后续尚未到点的安排；已到点或已完成的实例保留原记录。
- 暂停后取消后续尚未到点的安排；恢复后从当前时刻继续安排，不为暂停期间补发提醒。
- 结束计划停止后续安排，保留已发生记录。重新建立相同事项时创建新计划。
- “删除本次任务”和“结束重复计划”使用不同操作与文案，避免误删整条计划。
- 删除本次重复任务仅移除该次有效安排，不影响之后的日期；首版不提供“仅本次修改时间”编辑模式。
- 结束日期为包含当天：该日期仍可产生执行实例，次日起不再产生。

### 4.4 跨天与历史

- 新的一天不依赖打卡，应用运行期间自动切换日期并生成当天清单。
- 昨天未完成的实例保留在原日期，不自动加入今天，不自动设为完成。
- “移到今天”保留任务实例身份与原始计划时间，改变其执行日期；同一天重复点击不产生副本。
- 对重复任务，移来的旧实例和今天原本的实例可以同时存在，界面应标明旧实例的原日期。
- 历史中的完成和撤销操作更新该实例所属执行日期的统计。

## 5 提醒与时间规则

| 场景 | 期望行为 |
| --- | --- |
| 正常运行到点 | 向系统提交一次通知；窗口可见时显示宠物提醒气泡；**若开启提醒铃声，同步播放清脆摇铃音效** |
| 同时多项到点 | 汇总提示，点击进入到点任务列表；不连续抢占界面，铃声仅播放一次 |
| 窗口隐藏 | 继续调度和提交系统通知，不强制弹出主窗口 |
| 已完成或已删除 | 不再提醒该实例 |
| 撤销完成 | 已提醒过的实例不立即重复提醒；尚未到点且未提醒的实例正常等待到点 |
| 休眠后恢复或重新启动 | 汇总当天已到点、未完成且未提醒的事项；不逐条补发旧日期通知 |
| 系统拒绝或关闭通知 | 任务继续可用；显示通知不可用状态与系统设置指引，不标记任务完成；组件内气泡与摇铃音效仍可正常工作 |
| 退出或电脑关机 | 应用不再产生新提醒；下次启动恢复数据并执行当日检查 |
| 日期或系统时间改变 | 按当前时间重新计算后续安排，不通过倒计时累计推测日期 |

提醒结果与任务完成状态独立。应用应持久化提醒处理记录，避免普通重启和重复调度造成连续通知。系统是否展示通知受系统设置控制；应用需要记录提交或失败状态，不能将“提交成功”展示为“用户已经收到”。

## 6 宠物与桌面交互

| 事件 | 动画与交互 |
| --- | --- |
| 待机 | 循环呼吸、眨眼或小动作 |
| 点击 | 播放回应动作，可出现简短气泡 |
| 完成一项任务 | 播放一次开心或庆祝动作 |
| 全部任务完成 | 播放一次单独的庆祝反馈 |
| 到点提醒 | 播放摇铃或场景提醒动作与任务气泡，伴随清脆摇铃声（可开关），点击气泡进入对应任务 |
| 拖动 | 宠物与任务组件共同移动，释放后记住窗口位置 |
| 边缘缩放 | 展开态下拖拽窗口右下角自由拉大/缩小尺寸，释放后记住自定义尺寸 |
| 窗口隐藏 | 暂停无意义的动画播放，提醒调度继续运行 |

点击与拖动必须区分，拖动结束不额外触发点击。按钮、输入框、任务勾选区域和缩放手柄不应触发窗口位置移动。提醒气泡结束后仍可从任务列表找到未完成任务。

精灵图素材需要约定透明背景、帧宽高、行列、帧数、播放速度、循环规则和角色锚点。首版由开发者接入素材，不包含面向用户的素材编辑器或导入工具。正式分发前记录素材来源与适用授权。

## 7 窗口与本地使用

- **窗口自由拉大与尺寸记忆**：展开态支持用户拖拽右下角缩放手柄自定义宽高（最小宽高限制为 `356 × 480 px` 防止布局挤压变形），任务列表随高度自动延展以容纳更多计划；重启或从仅桌宠模式重新展开时恢复用户上次自定义的尺寸，并提供一键恢复默认尺寸（`356 × 480 px`），大号预设为 `440 × 610 px`。
- **置顶与「仅显示在桌面」快捷切换**：
  - 界面顶栏、宠物右键菜单与托盘/菜单栏提供一键切换 **「📌 始终置顶」** 与 **「🖥 仅留在桌面」**；
  - 选择「仅留在桌面」时，取消窗口置顶（`alwaysOnTop = false`）并隐藏任务栏图标（`skipTaskbar = true`），使组件平时安静待在桌面壁纸上方，当用户打开浏览器、文档等其他软件窗口时自然遮挡在背后，不打扰办公。
- **开机自启动**：默认关闭，设置面板与系统托盘/菜单栏支持开启或关闭「开机自动启动」，通过系统登录项（`setLoginItemSettings`）持久化生效。
- 隐藏保留进程和后台入口；重新显示恢复当前任务状态。
- 点击组件关闭按钮时展示三个选择。托盘或菜单栏中的“退出软件”是直接表达退出意图的入口。
- macOS 的系统退出菜单与快捷键遵循退出语义，避免被组件关闭选择反复拦截；此行为在原型中核对。
- 退出时完成必要持久化，但正常操作时即保存，不能只在退出时保存数据。
- 记住窗口位置与自定义展开尺寸；显示器断开或分辨率变化后，恢复到当前可见屏幕范围内。
- 重复启动时优先显示已有实例，避免多个调度器重复提醒。
- 安装新版本时保留本地数据；卸载时的数据保留策略在发布阶段明确。

| 编号 | 场景 | 通过标准 |

## 9 后续范围与待明确项

后续可增加法定节假日智能跳过、自定义天/周间隔重复、贪睡与稍后提醒、用户导入素材包、备份导入导出及轻量打卡。账号、跨设备同步和服务端不在当前产品范围内。

原型阶段需明确：界面布局与尺寸、窗口默认是否置顶、正式支持的系统版本与芯片架构、是否需要旧通知在应用退出后点击重新启动，以及未运行期间是否需要补齐所有历史安排。完整桌面游走、跨全屏空间显示不作为首版默认验收目标。

## 10 优化原型与架构对接

用户接受优化后的原型并进入架构设计。布局与交互采用当前 [HTML 原型](dual-platform-prototype.html) 与 [原型设计](prototype-design.md)；正式实现按 [应用架构](architecture.md) 和 [数据模型](data-model.md) 分离界面、业务与原生能力。

- 纳入完整清单、仅桌宠、后台隐藏三种使用模式。仅桌宠仍保留气泡与今日摘要，后台隐藏继续提醒。
- 采用原型中的日期查看、任务编辑、计划编辑、时间槽增删和气泡直接完成任务。
- 提醒优先于普通互动和完成反馈；气泡与列表操作同一个任务实例。
- 窗口初始尺寸以 356 × 480 逻辑像素为起点，支持展开态拖拽右下角自由拉大并记忆尺寸；仅桌宠的原生边界需要实际缩小，具体尺寸在 M0 验证。
- 原型中的宠物资源选择、参数和导入纳入架构，作为独立扩展批次实现；核心任务闭环仍先接入内置素材，扩展工期单列。
- 已到点、已完成及手动迁移记录按历史保护规则保留。原型示例中的数组清理逻辑不替代正式业务规则。
- 未来日期查看提供计划预览，历史仅展示实际生成记录；简单读取不补造任务。
- 2026-11-03 日期交互调整：日期入口仅保留日历图标，悬停提示用途；覆盖浮层说明「查看历史待办和未来安排，选一天即可切换」，选完自动关闭；已有记录在月历标点。日期、进度和返回今天合并为一行，不通过叠加选择条挤压清单。
- 2026-11-03 用户试用反馈升级（v0.3）：
  1. **开机自启动**：设置面板与托盘菜单新增「开机自动启动」开关；
  2. **仅留在桌面（防遮挡其他软件）**：顶栏新增 `📌 置顶 / 🖥 贴桌面` 一键切换按钮，并提供其他应用窗口遮挡演示；
  3. **框框自由拉大**：卡片右下角及边缘支持拖拽自由调整宽高，解决计划多时看不清的问题，并支持一键重置标准尺寸；
  4. **紧急任务优先排序**：支持标记「🔥 紧急」与「普通日常」，紧急任务自动置顶排列；
  5. **周计划与月计划**：重复计划扩展支持 `每天`、`每周（多选周几）`、`每月（多选几号）` 三种周期；
  6. **提醒摇铃声音**：内置清脆摇铃音效合成与播放，支持音效开关与一键试听。

系统版本、架构与退出后旧通知激活范围仍以安装包验证结果确定。此轮接受的是原型交互，未将模拟托盘、通知或存储标记为原生验收通过。
