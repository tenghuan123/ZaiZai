# 草莓兔女孩 · V3 表情与自然挥手修订

这次回应“挥手不自然、后续动作始终睁眼且表情相同”的反馈，使用内置 image_gen 重画挥手，基于 V2 身体动作修订其余五组的脸部；待机沿用 V2。

## 本轮修订

- 挥手改为放松肩膀、屈肘，用前臂与手腕摆动，去掉整条手臂伸直的大幅横扫与身体左右摇晃。
- 庆祝、欢呼、提醒、喝水、拉伸恢复完整开合的眨眼；闭眼帧使用短曝光，避免长时间半闭眼。
- 表情随动作变化：期待、喜悦、留意、专注抿嘴、呼气和满足，结束时回到放松状态。
- 对几组的半开眼状态做了二次修订；拉伸略过一张过早闭眼的候选帧，避免闭合—展开—再闭合的抖动。
- 不增加绘制帧数量来代替动作修改。本轮仍是每组 24 张候选绘制帧，播放曝光按实际候选筛选和配时。

## 查看与使用

- preview.html：独立离线 V2/V3 对比，可切换七组动作，带面部放大、逐帧、慢放与每组的“跳到眨眼”。
- manifest.json 与根目录 <动作>.png：8 列、每帧 320 × 320，24 FPS 的普通精灵图；曝光节奏已烘焙。
- animations/<动作>.png：APNG，与精灵图一致，帧时长精确为 1/24 秒；单次/循环遵循 manifest。
- previews/react-loop.png：用于展示自然挥手与眨眼的循环 APNG；应用动作仍遵循 manifest 的单次播放规则。
- keyframes/<动作>/00.png 至 23.png：候选绘制帧，播放顺序见 source/timelines.json。本包省略重复曝光帧的独立副本。
- comparison/v2：离线对比所需的 V2 图与配置。
- source/reference.png、source/prompts.md、source/generation.json：参考图、完整提示词与制作记录。
