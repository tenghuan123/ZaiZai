# 草莓兔女孩 · V3.1 待机角色一致性重绘

V3.1 以现有待机原图为角色外观基准，使用内置 image_gen 重绘鼓掌庆祝、跳跃欢呼和喝水提醒，统一衣服、发饰、配色和笔触。待机保持原样，其他动作沿用 V3.0.1 的显示基线。下方保留历史修订说明与本轮制作记录。

## 历史：V3 表情与自然挥手修订

- 挥手改为放松肩膀、屈肘，用前臂与手腕摆动，去掉整条手臂伸直的大幅横扫与身体左右摇晃。
- 庆祝、欢呼、提醒、喝水、拉伸恢复完整开合的眨眼；闭眼帧使用短曝光，避免长时间半闭眼。
- 表情随动作变化：期待、喜悦、留意、专注抿嘴、呼气和满足，结束时回到放松状态。
- 对几组的半开眼状态做了二次修订；拉伸略过一张过早闭眼的候选帧，避免闭合—展开—再闭合的抖动。
- 不增加绘制帧数量来代替动作修改。本轮仍是每组 24 张候选绘制帧，播放曝光按实际候选筛选和配时。

## 查看与使用

- preview.html：当前 V3 的本地预览，可切换七组动作，带面部放大、逐帧、慢放与每组的“跳到眨眼”；需与本目录图片一起打开。
- `manifest.json` 与根目录的动作 PNG 是应用使用的图集。每格 320 × 320，8 列，重复的画面只存一份。`frames` 与 `fps` 定义播放时长，`frameIndices` 把每个播放帧映射到图集中的格子。
- animations/<动作>.png：APNG，与精灵图一致，帧时长精确为 1/24 秒；单次/循环遵循 manifest。
- previews/react-loop.png：用于展示自然挥手与眨眼的循环 APNG；应用动作仍遵循 manifest 的单次播放规则。
- keyframes/<动作>/00.png 至 23.png：候选绘制帧，播放顺序见 source/timelines.json。本包省略重复曝光帧的独立副本。
- source/reference.png、source/prompts.md、source/generation.json：参考图、完整提示词与制作记录。

重新导出动作时，先在临时目录生成逐播放帧排列的 PNG，再从本目录运行 `python3 source/compact-atlases.py /path/to/exports/idle.png`（需要 Pillow，可一次传入多个动作）。脚本更新图集、`manifest.json` 和离线预览内嵌的动作配置。

| 动作 | 眨眼所在阶段 | 主要表情变化 |
| --- | --- | --- |
| 待机 | 每约 4 秒一次 | 平静、轻微呼吸 |
| 挥手 | 挥手停顿处 | 注意到你 → 微笑招呼 → 放松 |

该资源现已接入当前应用的内置播放器，顶栏 `🐾` 可在软件中连续预览七组动作。图像为生成式逐帧素材，发丝、蕾丝和局部五官细节仍有少量帧间变化。

当前应用使用 `strawberry-bunny-v3`（3.1.0）。V1、V2 资源目录、旧版对比副本与相关旧导出 ZIP 已清理；历史制作说明保留，旧版本可从 Git 历史恢复。

## V3.0.1 · 按待机校准动作体型

原素材把各组站立高度做到了接近，但部分动作的头部更大、身体更短，切换时仍会显得忽大忽小。应用播放器与本地预览现在共同使用 manifest 中各动作的 `proportions`：以待机的头顶、颈部、脚底为基准，头部等比缩放，身体长度相应补偿，避免缩小头部时整个人也变矮。待机图像保持原样。

`headScale` 控制头部的等比缩放和整个人物的横向尺度；`bodyScale` 控制颈部以下的纵向长度；`neckY` 为源图分界，`footY` 为保留位置的脚底锚点。可选 `poses` 是 `[起始播放帧, 颈部 Y, 脚底 Y]`，持续到下一条记录。跳跃动作按姿势更新这两个位置，保留蓄力下蹲和离地高度；各动作的眨眼、曝光节奏、表情与循环规则保持原样。校准记录见 `source/proportions.json`。

这是显示校准，原始 PNG、候选帧和 APNG 保留制作原图。接入其他播放器时应一并读取 `proportions`；直接播放 APNG 不会包含这次显示校准。

验证：`npm run build`、49 项规则测试、七组动作共 536 帧的越界与预览一致性检查，以及 macOS arm64 打包后四个角色的播放验收通过。可用 `node --import tsx scripts/bunny-proportions-smoke.mjs` 复验显示校准；前后对比与报告见 `docs/bunny-proportions-evidence/`。

## V3.0.2 · 三组动作继续缩小头部

鼓掌庆祝、跳跃欢呼、喝水提醒在 V3.0.1 的基础上，头部等比尺度分别再缩小约 11%、8%、9%，按待机的脸部轮廓和眼距复核。保留既有身体纵向比例、颈部与脚底位置和跳跃姿势锚点；不再为了对齐帽顶而放大脸部。其他四组动作参数不变。

V3.0.2 验证：构建、49 项规则测试、打包应用与资源预览的 536 帧一致性及越界检查通过；脸部放大与各动作阶段的对比见 `docs/bunny-proportions-evidence/v3.0.2/`。

## V3.1.0 · 按待机原图重绘三组动作

以用户更喜欢的 `bunny-proportions/mac-arm64`（V3.0.1）为显示基线，内置 image_gen 使用 `keyframes/idle/00.png` 作为唯一角色外观基准，重绘鼓掌庆祝、跳跃欢呼和喝水提醒。旧动作仅提供姿势顺序，不继承其衣服、发饰和笔触。三组现在使用实际重绘的 PNG、候选帧和 APNG；不再套用头部与身体分段缩放。其他四组动作参数及原图保持原样。

三组统一采用待机的奶油色裙装、粉色蝴蝶结、双兔发饰、草莓装饰、发夹、长卷发与细辫，以及柔和的棕色线条和哑光笔触。鼓掌与欢呼的候选帧 0、1、2、22、23 直接复用待机原帧，使动作首尾精确接轨；中间帧保留动作表情。喝水保留小蓝杯，首尾均为低位持杯。

每组仍为 24 张候选帧，沿用现有曝光时间线、24 FPS 和循环规则。所有候选帧以一套等比尺度注册到 320 × 320 画布；鼓掌和喝水固定脚底，欢呼保留蓄力下蹲和离地位移。APNG 和精灵图从同一批候选帧导出，APNG 帧延迟精确为 1/24 秒。生成式中间帧仍有轻微的发丝、蕾丝细节变化。

制作记录位于 `source/redraw-v3.1/`：`prompts.json` 为三组完整提示词，`*-generated.png` 为内置 image_gen 原始输出，`idle-template.png` 与 `*-pose-guide.png` 为输入，`import.json` 记录等比尺度及逐帧锚点，`generation.json` 记录基线和素材哈希。`stage.mjs`、`export-apng.swift`、`fix-apng.mjs` 保留切帧、曝光导出与 APNG 配时的制作脚本。待机原帧保持不变。

V3.1 验证：构建、49 项规则测试、打包应用的 536 帧一致性与越界检查通过；鼓掌和欢呼的起始画面与待机像素完全一致，APNG 循环次数与 1/24 秒配时已校验。新旧对比和报告见 `docs/bunny-redraw-evidence/`。
